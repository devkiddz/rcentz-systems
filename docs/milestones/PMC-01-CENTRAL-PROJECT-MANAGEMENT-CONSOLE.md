# PMC-01 — Central Project Management Console

Status: In Progress
Repository: rcentz-systems
Database migration: None planned

## Objective
Establish a centralized Project Management Console governing all Rcentz Systems projects.

## Scope
- Central project monitoring and management.
- Cross-project health and delivery priorities.
- Milestone and governance visibility.
- GitHub development activity integration.
- Navigation to dedicated project workspaces.

## Constraints
- Preserve existing project records.
- Preserve existing Milestone Engine behavior.
- Preserve client authorization boundaries.
- Reuse current API and database models.
- No destructive database operations.

## Acceptance
- Central console displays authorized projects.
- Project health and milestones reflect real records.
- Project-specific management remains functional.
- Existing GitHub synchronization remains operational.
- TypeScript, lint, runtime and live deployment verification pass.
- Completion and sealing require verified evidence.
